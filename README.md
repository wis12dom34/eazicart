# EaziCart

EaziCart is a scalable commerce platform being prepared as a TypeScript-first monorepo.

## Planned workspace

The repository will support:

- Customer app
- Seller experience
- Admin
- Mobile app
- Backend / API
- Shared packages
- Future scalable infrastructure

## Status

Repository foundation only. Application development has not started yet.

## Security

Production secrets, API keys, credentials, and environment-specific private values must never be committed to this repository.
